# AA Dungeon Macro (Anime Adventures – Roblox)

มาโคร AutoHotkey v2 สำหรับโหมด **Dungeon** ในเกม Anime Adventures (Roblox) เล่นวนให้เองตั้งแต่เลือกห้องจนถึงห้องสุดท้าย

- เลือกห้องเองบนกระดาน Dungeon Run โดยดูชนิดห้องและห้องถัดไปด้วย เน้นห้องที่มีหีบ (Chest) และหลบห้อง Curse เมื่อลงลึก
- วางยูนิต อัปเกรด กดสกิล และเปิด auto ตามลำดับใน `plan.txt`
- วางยูนิตแบบสุ่มจุดใกล้ทางเดินของมอน ถ้าแมพไหนวางยาก จะหาจุดว่างทั่วทั้งแมพแทน
- เข้าร้านค้าแล้วซื้อของตามรายการ ของที่เขียนว่าเพิ่ม luck หรือลด placement cost จะซื้อก่อน ถ้ามีเหรียญเกิน 2000 จะซื้อทุกอย่าง และแคปหน้าร้านเก็บไว้ในโฟลเดอร์ `shots`
- เก็บหีบไว้เปิดตอนห้องสุดท้าย
- จบเกม (ชนะหรือแพ้) แล้วปิดหน้าต่าง Unit Overview และหน้าต่างยูนิตให้เอง จากนั้นไปห้องต่อไป
- ถ้ากล้องหลุดเป็นมุม first person จะแก้ให้เอง

> ⚠️ ใช้มาโครในเกมอาจผิดกฎของ Roblox/เกม ใช้ด้วยความเสี่ยงของตัวเอง

## สิ่งที่ต้องมี

| อย่าง | รายละเอียด |
|---|---|
| Windows 10 / 11 | มาโครใช้ OCR ของ Windows ในการอ่านตัวหนังสือในเกม |
| ภาษาอังกฤษใน Windows | ต้องมี **English (United States)** ใน Settings → Time & Language → Language (ดูวิธีเช็คด้านล่าง) |
| AutoHotkey **v2** | โหลดที่ <https://www.autohotkey.com/> เลือก v2 (v1 ใช้ไม่ได้) |
| จอ 1920×1080 | ตั้ง Display scale เป็น **100%** (Settings → System → Display) |
| Roblox | เปิดแบบเต็มจอ (Maximize หรือ F11) บน **จอหลัก** |
| ภาษาเกม | ภาษาอังกฤษ |

### เช็คว่ามี OCR ภาษาอังกฤษแล้วหรือยัง
เปิด PowerShell แบบ Administrator แล้วพิมพ์:
```powershell
Get-WindowsCapability -Online | Where-Object Name -like 'Language.OCR*en-US*'
```
ถ้า `State` เป็น `NotPresent` ให้ติดตั้งด้วยคำสั่งนี้:
```powershell
Add-WindowsCapability -Online -Name "Language.OCR~~~en-US~0.0.1.0"
```

## ติดตั้ง

1. กดปุ่มเขียว **Code → Download ZIP** แล้วแตกไฟล์ไว้ที่ไหนก็ได้ เช่น `Documents\AAMacro`
2. ตรวจว่าในโฟลเดอร์มีไฟล์ครบ:
   ```
   AADungeon.ahk          ← ตัวมาโคร
   AASettings.ahk         ← หน้าต่างตั้งค่า (แก้แผน/ห้อง/ร้านค้า/ราคา) + อัปเดต + รายงานบั๊ก
   settings.example.ini   ← ค่าตั้งต้น (ครั้งแรกมาโครจะคัดลอกเป็น settings.ini ให้เอง)
   plan.example.txt       ← แผนตัวอย่าง (ครั้งแรกจะคัดลอกเป็น plan.txt ให้เอง)
   Lib\OCR.ahk            ← ไลบรารีอ่านตัวหนังสือ (ห้ามย้าย)
   ```
3. ดับเบิลคลิก `AADungeon.ahk` จะมีข้อความเล็กๆ มุมซ้ายล่างว่า **"AA Dungeon ready - F2 start"**

## อัปเดตเป็นเวอร์ชันใหม่ (การตั้งค่าไม่หาย)

กด **F8** → ปุ่ม **🔄 อัปเดตมาโคร** มาโครจะโหลดเฉพาะไฟล์โปรแกรม (`AADungeon.ahk`, `AASettings.ahk`, `Lib\OCR.ahk`) มาทับ
**`settings.ini` กับ `plan.txt` ของคุณจะไม่ถูกแตะ** ไฟล์เก่าจะสำรองไว้ในโฟลเดอร์ `backup`

ตอนเปิดมาโคร ถ้ามีเวอร์ชันใหม่ ข้อความมุมซ้ายล่างจะขึ้นว่า `update available: F8 > Update`

ถ้าโหลด ZIP ใหม่จาก GitHub เองก็ได้ แตกทับโฟลเดอร์เดิมได้เลย ใน ZIP ไม่มี `settings.ini`/`plan.txt` จึงไม่ทับของคุณ

## วิธีใช้

1. เข้าเกม Anime Adventures แล้วเปิด Roblox เต็มจอ
2. จัด hotbar ช่อง 1–6 ให้ตรงกับ `plan.txt` (ดูหัวข้อถัดไป)
3. แก้ราคาวางยูนิต `Cost1`–`Cost6` ใน `settings.ini` ให้ตรงกับยูนิตของตัวเอง
4. ไปที่หน้า Dungeon (ในล็อบบี้ หรือหน้าเลือกห้อง Dungeon Run ก็ได้) แล้วคลิกในเกม 1 ครั้งเพื่อโฟกัสหน้าต่าง
5. กด **F2** เพื่อเริ่ม

| ปุ่ม | ทำอะไร |
|---|---|
| **F2** | เริ่ม |
| **F3** | หยุด (รีโหลดมาโคร) |
| **F4** | พัก / เล่นต่อ |
| F5 | เขียนข้อความที่มาโครอ่านได้จากจอลงใน log (ใช้ตอนหาบั๊ก) |
| F6 / F7 | ทดสอบตั้งกล้องมุมบน |
| **F8** | เปิดหน้าต่างตั้งค่า |
| **F9** | ส่งรายงานบั๊ก |

> ระหว่างที่มาโครทำงาน อย่าขยับเมาส์ อย่าสลับหน้าต่าง และอย่าเอาหน้าต่างอื่นมาบังเกม

## หน้าต่างตั้งค่า (ไม่ต้องแก้ไฟล์เอง)

เปิดได้ 2 ทาง: ดับเบิลคลิก `AASettings.ahk` หรือกด **F8** ตอนที่มาโครเปิดอยู่

| แท็บ | ใช้ทำอะไร |
|---|---|
| **แผนวางยูนิต** | ตารางขั้นตอนของแผน ใช้ส่วนล่างสร้างขั้นตอนใหม่ เลือกคำสั่ง ติ๊กช่องยูนิต ใส่จำนวน แล้วกด "เพิ่มต่อท้าย" ถ้าจะแก้แถวไหน คลิกแถวนั้นก่อน แล้วกด "แก้แถวที่เลือก" ใช้ปุ่ม ▲ ▼ เพื่อเลื่อนลำดับ |
| **เลือกห้อง** | คะแนนห้องแต่ละแบบ คะแนน Curse ตามความลึก และเงื่อนไข Shrine |
| **ร้านค้า** | ตอนเหรียญเกินเท่าไหร่ถึงจะซื้อทุกอย่าง กับรายการของที่อยากซื้อ (เพิ่ม/แก้/ลบ/เรียงได้) |
| **ราคายูนิต / ทั่วไป** | ราคาวางยูนิตช่อง 1–6, เก็บหีบไว้เปิดห้องสุดท้าย, โหวตอัตโนมัติ, จบดันแล้วจะเริ่มใหม่หรือหยุด |

แก้เสร็จแล้วกด **บันทึก** แล้วกด F3 ในมาโครเพื่อโหลดค่าใหม่ หรือกด **บันทึก + เปิดมาโครใหม่** ทีเดียวจบ (มาโครจะเปิดใหม่ แล้วค่อยกด F2 เพื่อเริ่ม)

ด้านล่างนี้เป็นรายละเอียดของไฟล์ สำหรับคนที่อยากแก้ไฟล์เอง

## `plan.txt` – ลำดับการเล่นในแต่ละห้อง

เขียนทีละบรรทัด มาโครจะทำจากบนลงล่าง ข้อความหลังเครื่องหมาย `;` เป็นคอมเมนต์ มาโครจะข้ามไป ตัวเลข 1–6 คือ **ช่อง hotbar**

| คำสั่ง | ความหมาย |
|---|---|
| `place 1 x3` | วางยูนิตช่อง 1 จำนวน 3 ตัว (ท่าวางสุ่มใกล้ทาง) |
| `place 1 x3 far` | วางแบบระบุท่าวาง (ดูตารางท่าวางด้านล่าง) |
| `place 3 x1 at 900,500` | วางตรงจุดที่กำหนด (พิกัดจอ 1920×1080) ถ้าจุดนั้นวางไม่ได้จะหาจุดว่างที่ใกล้ที่สุด |
| `upgrade 1,2 max even` | อัปช่อง 1 และ 2 ให้ตัน โดยอัปสลับกันให้เลเวลเท่าๆ กัน |
| `upgrade 4 max` | อัปช่อง 4 ให้ตัน |
| `upgrade 5 max one` | อัปช่อง 5 ให้ตันทีละตัว |
| `upgrade 3 to 3` | อัปช่อง 3 ถึงเลเวล 3 |
| `upgrade 6 +1` | อัปช่อง 6 เพิ่ม 1 ขั้น |
| `upgrade 1,2 even until wave 5` | อัปช่อง 1, 2 ไปเรื่อยๆ จนถึงเวฟ 5 |
| `upgrade all max` | อัปทุกตัวให้ตัน |
| `ability 3 x2` | กดสกิลของยูนิตช่อง 3 สองครั้ง |
| `auto 6` | เปิดสกิล auto ของยูนิตช่อง 6 |
| `wait 5` | รอ 5 วินาที |
| `wave 7` | รอจนถึงเวฟ 7 |

**ท่าวาง** (ใส่ต่อท้ายคำสั่ง `place`)

| ท่าวาง | ความหมาย | เหมาะกับ |
|---|---|---|
| *(ไม่ใส่)* / `random` | สุ่มจุดห่างทางเดิน 30–120 px | ทั่วไป |
| `near` | ชิดทางเดินมากที่สุดเท่าที่วางได้ | ตัวตีระยะสั้น |
| `far` | ไกลทางเดินมากที่สุด | ตัวฟาร์มเงิน (ไม่ต้องตี ไม่แย่งที่ดีๆ) |
| `group` | วางติดตัวแรกของช่องเดียวกัน หรือติดกลุ่มล่าสุดที่วางแบบ group | ตัวบัฟ / ซัพพอร์ต |
| `spread` | ห่างจากยูนิตตัวอื่นให้มากที่สุด แต่ยังใกล้ทาง | ตีได้ทั่วแมพ |
| `cover` | จุดที่ทางเดินผ่านเยอะที่สุด (ตรงโค้ง/มุม) | ตัวตีวงกว้าง |
| `center` | ใกล้กลางจอที่สุด | แมพที่ทางวนรอบกลาง |
| `at X,Y` | ตรงจุดที่กำหนดเอง | แมพที่รู้ว่าจุดไหนดี |

ในหน้าต่างตั้งค่า เลือกท่าวางได้จากช่อง **ท่าวาง** ถ้าเลือก "กำหนดจุดเอง" ให้กด **🎯 เลือกจุดบนจอเกม** แล้วคลิกบนจอเกมตรงจุดที่ต้องการ (คลิกนี้จะไม่ไปกดอะไรในเกม) กดตอนอยู่ในด่านจะเห็นตำแหน่งจริงที่สุด

**ยูนิตเนิน (hill)** – ตั้งประเภทยูนิตในแท็บ "ยูนิต / ทั่วไป" ของหน้าต่างตั้งค่า
- ตอนหน้าโหวตเริ่มเกม (ก่อนกด Yes) มาโครจะถือยูนิตเนินขึ้นมาดูว่าโซนสีเขียวอยู่ตรงไหน ถ้าบนจอไม่มีเลย จะเดิน W → D → S → A ทางละ `HillWalk` วินาทีจนเจอ แล้ว**ยืนอยู่ตรงนั้น**ค่อยกดเริ่มเกม (ทางที่ไม่เจอจะเดินกลับก่อนลองทางถัดไป) ยูนิตพื้นดินจะไม่วางทับโซนเขียว
- ยูนิตเนินจะวางเฉพาะในโซนสีเขียว (ท่าวางยังใช้ได้ เช่น `cover` = จุดในโซนเขียวที่ใกล้ทางเดินที่สุด)
- ทุกจุดที่เช็ค ถ้าไม่เห็นโซนเขียว จะลองซูมเข้าทีละนิด (`HillZoomStep` ขีด สูงสุด `HillZoomTries` ครั้ง) ถ้าเจอหลังซูม จะล็อกระยะกล้องนั้นไว้ใช้ต่อทั้งรัน ถ้าไม่เจอจะซูมกลับเท่าเดิม แล้วค่อยเดินต่อ (เดินแบบกด Shift วิ่ง)
- ถ้าบนจอไม่มีโซนเขียว มาโครจะเดิน W → D → S → A ทางละ `HillWalk` วินาที ทางไหนเจอก็วางเลย แล้วเดินกลับที่เดิมทุกครั้ง ถ้าครบ 4 ทางแล้วยังไม่เจอ จะข้ามยูนิตนั้นในด่านนั้น ด่านต่อไปจะลองทางที่เคยเจอก่อน

พิมพ์เป็นภาษาไทยก็ได้ เช่น `วาง` `อัป` `สกิล` `ออโต้` `รอ` `เวฟ` `ตัน` `เฉลี่ย` `ทีละตัว` และท่าวาง `สุ่ม` `ชิดทาง` `ไกล` `กลุ่ม` `กระจาย` `โค้ง` `กลาง` `จุด`

ถ้า plan มีบรรทัดผิด มาโครจะไม่เริ่ม และบอกบรรทัดที่ผิดไว้ใน `AADungeon.log`

**เคล็ดลับ:** ให้วางตัวฟาร์มเงินก่อน แล้วอัปตัวฟาร์มให้ตันเร็วๆ ส่วนแผนในไฟล์เป็นแผนตัวอย่างของเจ้าของมาโคร ต้องแก้ให้ตรงกับยูนิตของตัวเอง

## `settings.ini` – ตั้งค่า

แก้ด้วย Notepad แล้วกด F3 ในมาโครเพื่อโหลดค่าใหม่ ถ้าลบไฟล์ทิ้ง มาโครจะสร้างไฟล์ใหม่พร้อมค่าเริ่มต้นให้

| ค่า | ความหมาย |
|---|---|
| `Cost1`–`Cost6` | ราคาวางยูนิตแต่ละช่อง (มาโครจะรอจนมีเงินพอก่อนวาง) **ต้องแก้** |
| `Type1`–`Type6` | ประเภทยูนิต `ground` (พื้นดิน) หรือ `hill` (เนิน วางได้แค่บนโซนสีเขียว) |
| `HillWalk` | ถ้าบนจอไม่มีโซนเนิน จะเดินหาทางละกี่วินาที (ค่าเริ่มต้น 2.5) |
| `HillRun` | 1 = กด Shift วิ่งตอนเดินหาเนิน |
| `HillZoomStep` / `HillZoomTries` | ถ้าไม่เห็นเนิน ซูมเข้าทีละกี่ขีด / สูงสุดกี่ครั้ง (เจอหลังซูม = ล็อกระยะกล้องนั้นไว้ใช้ต่อ) |
| `CamZoom` | ระยะกล้อง: ซูมออกกี่ขีดจากซูมเข้าสุด (0–30, ค่าเริ่มต้น 24 มาก = ไกล) |
| `Boss` `Chest` `Hoard` `Shrine` `Open` `Normal` | คะแนนของห้องแต่ละแบบ คะแนนสูง = อยากเข้าห้องนั้นมาก |
| `Curse` / `CurseMid` / `CurseHigh` | คะแนนห้อง Curse (ติดลบ = เลี่ยง) จะลบหนักขึ้นเมื่อลึกเกิน `CurseMidDepth` / `CurseHighDepth` |
| `Lookahead` | ให้น้ำหนักกับห้องถัดไปแค่ไหน (0 = ไม่ดูห้องถัดไปเลย) |
| `ShopRich` / `ShopMid` / `ShopPoor` | คะแนนห้องร้านค้า ขึ้นกับว่ามีเหรียญเท่าไหร่ |
| `ShopBuyAll` | ถ้ามีเหรียญมากกว่านี้ จะซื้อของทุกอย่างในร้าน (ค่าเริ่มต้น 2000) |
| `Items` | รายการของที่จะซื้อ รูปแบบ `ชื่อ=คะแนน` ถ้าใส่ `>500` ต่อท้าย = ซื้อเฉพาะตอนมีเหรียญเกิน 500 |
| `Shrine*` | เงื่อนไขการรับ/ปฏิเสธ Shrine |
| `SaveChests` | 1 = เก็บหีบไว้เปิดห้องสุดท้าย |
| `AutoVote` | 1 = กดโหวต Yes ให้อัตโนมัติ |
| `OnFinish` | `again` = จบดันแล้วเริ่มใหม่ / `stop` = หยุด |

| กล้องเป็นมุม first person | มาโครจะแก้ให้เอง ถ้ายังค้างอยู่ให้ซูมออกด้วยลูกกลิ้งเมาส์แล้วกด F3 → F2 |
| หน้าต่างอื่นเด้งมาบัง (Discord, Game Bar, NVIDIA overlay) | ปิด overlay พวกนั้นก่อนเปิดมาโคร |
| อยากรู้ว่ามาโครทำอะไรไปบ้าง | เปิดดู `AADungeon.log` ในโฟลเดอร์เดียวกัน |

### ส่งรายงานบั๊กให้ผู้พัฒนา
1. กด **F9** ตอนที่มาโครเปิดอยู่ หรือกดปุ่ม **🐞 รายงานบั๊ก** ในหน้าต่างตั้งค่า
2. พิมพ์สั้นๆ ว่าเกิดอะไรขึ้น แล้วกด OK
3. หน้า **แจ้งบั๊กบน GitHub** จะเปิดขึ้นมา ช่อง "เกิดอะไรขึ้น" กรอกให้แล้ว และ **log ถูกคัดลอกไว้ให้แล้ว**
4. คลิกช่อง **log ของมาโคร** แล้วกด **Ctrl+V** จากนั้นกด **Create** (ต้องมีบัญชี GitHub)
5. ระบบจะอ่าน log แล้วตอบ/แก้ให้อัตโนมัติภายในไม่กี่นาที

ไม่ต้องอัปโหลดไฟล์แล้ว (เคยอัปโหลดไม่ผ่าน) แต่ไฟล์ `bug_reports\bug_report_....zip` ยังสร้างไว้ให้ ถ้าอยากแนบเพิ่มก็ได้ (ใน log อาจมีชื่อผู้เล่นในเกมของคุณ)

ถ้ามีภาพหน้าจอตอนที่ค้าง แนบมาด้วยจะช่วยได้มาก
